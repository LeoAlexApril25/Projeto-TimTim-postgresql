# Projeto-TimTim

🍫 TimTim - Sistema de Gestão para Confeitaria

O TimTim é uma solução robusta de backend desenvolvida para transformar a gestão de pequenos negócios de confeitaria, saindo do controle manual para uma plataforma digital inteligente e automatizada.

📝 Descrição do Projeto

O backend do TimTim foi construído para gerenciar todo o ciclo de vida de uma confeitaria: desde a compra de ingredientes e cálculo de custos de receitas até o registro de produção diária, vendas e análise de lucro líquido. O sistema foca em fornecer inteligência financeira, permitindo que o empreendedor saiba exatamente quanto está ganhando em cada doce vendido.




🚀 Jornada de Desenvolvimento (Timeline)

📅 Fase 1: Fundação e Estrutura (Abril/2026)

•
Configuração do Ambiente: Inicialização do Node.js, Express e conexão com banco de dados MySQL.

•
Módulo de Ingredientes: Criação de CRUD completo para gestão de insumos e custos unitários.

•
Módulo de Produtos: Cadastro de produtos finais com definição de preços de venda.

•
Ficha Técnica (Receitas): Implementação da lógica que vincula ingredientes a produtos, calculando o custo de produção automaticamente.

📅 Fase 2: Operação e Inteligência (Abril/2026)

•
Módulo de Produção: Registro diário de fabricação de doces.

•
Módulo de Vendas: Registro de saídas e integração com faturamento.

•
Relatórios Financeiros: Desenvolvimento do motor de cálculo de lucro líquido (Vendas - Custos de Receita).

•
Gestão de Despesas: Implementação de lançamentos manuais para custos fixos e variáveis (embalagens, luz, etc.).

📅 Fase 3: Segurança e Expansão (Em andamento)

•
Middlewares Profissionais: Implementação de Logger (monitoramento) e Validadores de dados.

•
Segurança Avançada: Implementação de criptografia de senhas com Bcrypt e autenticação via JWT.

•
Recuperação de Senha: Integração com Nodemailer para sistema de "Esqueci minha senha" via e-mail.

•
Próximos Passos: Gestão de Clientes (CRM) e Baixa Automática de Estoque.




🛠️ Tecnologias Utilizadas

•
Linguagem: Node.js (JavaScript)

•
Framework: Express.js

•
Banco de Dados: MySQL

•
Segurança: Bcryptjs, JSON Web Token (JWT)

•
Comunicação: Nodemailer

•
Ferramentas: MySQL, Thunder Client, Git
